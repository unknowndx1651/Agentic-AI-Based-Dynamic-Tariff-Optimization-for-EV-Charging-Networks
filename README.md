## Overview  
This project builds an **Agentic AI framework** for dynamic tariff optimization across EV charging networks using large-scale real-world charging session data. The system autonomously predicts charging demand 1 hour ahead, recommends optimal per-kWh tariffs in real time, and evaluates pricing decisions through a monitoring and feedback loop — all aimed at maximizing revenue, reducing congestion, and improving charger utilization.


## Problem Statement

EV charging stations operating on flat ₹/kWh pricing face mounting inefficiencies:

- Peak-hour congestion and long user wait times
- Charger underutilization during off-peak windows
- Rising electricity procurement costs
- Deteriorating user experience

This project replaces static pricing with an intelligent, data-driven dynamic tariff engine that responds to real-time demand signals.

## Datasets

### 1. ACN-Data (Adaptive Charging Network)
- **Source:** https://ev.caltech.edu/dataset.html
- **Coverage:** 15,013 EV charging sessions from Caltech sites (04/25/2018 00:00 to 12/16/2018 23:55)
- **Format:** JSON → converted to CSV
- **Key fields:** connectionTime, disconnectTime, kWhDelivered, stationID, userID

### 2. UrbanEV Dataset (ST-EVCDP)
- **Source:** https://github.com/IntelligentSystemsLab/ST-EVCDP
- **Coverage:** 247 charging stations, 8,640 time slots at 5-minute intervals (June 19 – July 18, 2022), Shenzhen, China
- **Files:** occupancy.csv, volume.csv, price.csv, duration.csv, time.csv, stations.csv, information.csv, distance.csv, adj.csv

**Note:** Raw data files are not included in this repository due to size constraints. Download them from the links above and place them in data/raw/ before running the notebooks.

## Notebooks — Run Order

**Important:** Notebooks must be run in order. Each notebook depends on outputs from the previous one.

### Notebook 1 — Data Preprocessing (01_data_preprocessing.ipynb)
- Converts ACN JSON to structured DataFrame
- Melts UrbanEV wide-format matrices (8,640 × 248) into long format
- Merges all data sources into unified analytical base
- Engineers key features: Charger Utilization Rate, Revenue per Session, Queue Length Proxy, Occupancy Density
- Handles missing values with documented assumptions
- **Output: clean_urban_data.csv (2,134,080 rows × 32 cols), clean_acn_data.csv (15,013 rows × 28 cols)**

### Notebook 2 — Exploratory Data Analysis (02_eda.ipynb)
- Intraday demand patterns across all 247 stations
- Weekday vs weekend behavioral analysis
- Station utilization heatmap (top 40 busiest stations)
- Peak vs off-peak volatility quantification
- ACN session duration, energy, and revenue distributions
- Congestion and underutilization analysis
- Price multiplier vs utilization alignment check
- **Output: 4 summary CSVs, 8 visualization PNGs**

### Notebook 3 — Demand Prediction Agent (03_demand_prediction_agent.ipynb)
- **Forecast horizon:** 1 hour ahead (12 × 5-minute slots)
- **Feature engineering:** Legitimate lag features only (no target leakage)
- **Train/test split:** Time-based 80/20 (no random shuffling)
- **Models trained:** XGBoost, LightGBM, Random Forest, Ridge
- **Best model:** XGBoost — R² = 91.9%, minimal train/test gap (no overfitting)
- **Output: demand_predictions.csv (426,816 rows), trained model .pkl, demand_model_scores.csv**

### Notebook 4 — Tariff Pricing Agent (04_tariff_pricing_agent.ipynb)
- Rule-based dynamic tariff engine:
  - Surge zone (utilization > 80%): linear scale up to ₹24/kWh (+60%)
  - Discount zone (utilization < 30%): conservative scale down to ₹13.20/kWh (−12%)
  - Baseline zone (30–80%): mild ±3% adjustment
- Volume-adjusted revenue simulation (demand responds to price)
- Demand elasticity: −15% surge, +20% discount
- **Output: tariff_recommendations.csv, revenue_comparison.csv, utilization_before_after.csv, offpeak_uplift.csv**

### Notebook 5 — Monitoring & Learning Agent (05_monitoring_learning_agent.ipynb)
- Evaluates pricing decisions across **6 evaluation episodes** (1 day each)
- Tracks per-episode: revenue gain, pricing efficiency, wait time reduction, customer response rate
- Visualizes feedback loop performance across episodes
- **Output: agent_performance_metrics.csv, feedback_loop_improvement.csv**
